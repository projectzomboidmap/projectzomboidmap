# Project Zomboid Map

I keep a free interactive map of Build 42's Knox Country and a database of
every item in the game — every street, every floor, every axe.

## What I'm building

* **The map** — the full B42 world in a browser tab: zoom from the whole
  county to a single room, switch floors, plan routes, search 5,092 items
  and see where they spawn.
* **Knox Country Base Atlas** — the best base locations in Build 42, rated
  from the map's own data instead of opinion. Zombie pressure is measured,
  not guessed. The first five scored locations are published in the atlas
  repository here on GitHub.
* **Knox Country Safehouse Jam** — a building jam I host on itch.io: build
  the safehouse you'd trust with your life. Submissions open 23 November;
  the top three get featured with screenshots and creator credit.
