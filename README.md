# Project Zomboid Map

I keep a free interactive map of Build 42's Knox Country and a database of
every item in the game — every street, every floor, every axe — at
**[ProjectZomboidMap.net](https://projectzomboidmap.net)**.

## What I'm building

* **[The map](https://projectzomboidmap.net)** — the full B42 world in a
  browser tab: zoom from the whole county to a single room, switch floors,
  plan routes, search 5,092 items and see where they spawn.
* **[Knox Country Base Atlas](https://github.com/projectzomboidmap/knox-country-base-atlas)** —
  the 50 best base locations in Build 42, rated from the map's own data
  instead of opinion. Zombie pressure is measured, not guessed.
* **[Knox Country Safehouse Jam](https://itch.io/jam/knox-country-safehouse-jam)** —
  a building jam I host on itch.io: build the safehouse you'd trust with
  your life. Winners get featured on the map site.
